/**
 * Peafowl chat stream module.
 *
 * Architecture
 * ------------
 * ```
 *  Client A ──socket──► Server 1 ──XADD──► Redis Stream (peafowl:chat:events)
 *                                              │
 *  Client B ──socket──► Server 2 ◄──XREAD─────┘
 *                         │
 *                         └──emit──► Client B
 * ```
 *
 * Socket handlers publish events via XADD instead of calling io.to().emit()
 * directly. Every server instance runs a blocking XREAD loop and broadcasts
 * to its local Socket.IO clients, enabling multi-instance deployments.
 */
